Геймдизайн: ветки кампании

Каждый заказчик — отдельная ветка кампании (см. GAME_DESIGN.md, «Orders & Collectors»). Для всех веток одна и та же лестница сложности: несколько заказов только по жанру, затем только по периоду, затем только по автору. У каждого заказчика свои значения жанра/периода/автора. После последнего заказа ветка бесконечно повторяет условия фазы «автор» («мастерство»). Тип аукциона, множитель бюджета и шанс трофея считаются автоматически по номеру заказа.
